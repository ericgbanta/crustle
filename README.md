# crustle

Crustle is a Bug/Rock-type Pokémon introduced in Generation V. It is also this project, which is named after the crab pokemon to honor Rustaceans that also enjoy pocket monsters. This is a simple Pokédex app built using [Rust](https://www.rust-lang.org/), [Tailwind](https://tailwindcss.com/) & [Dioxus](https://dioxuslabs.com/) (not to be confused with [Deoxys](https://bulbapedia.bulbagarden.net/wiki/Deoxys_(Pok%C3%A9mon))).

### Prerequisites

1. [Install Rust using rustup](https://www.rust-lang.org/tools/install). The `rust-toolchain.toml` in this repo tells rustup to install the stable toolchain, the `wasm32-unknown-unknown` target, clippy and rustfmt the first time you run a cargo command here.
2. Install the Dioxus CLI, version 0.7. With [cargo-binstall](https://github.com/cargo-bins/cargo-binstall), `cargo binstall dioxus-cli@0.7.10` downloads a prebuilt binary. `cargo install dioxus-cli@0.7.10` also works but compiles from source, which takes a while.

You don't need Node.js. The `dx` CLI runs Tailwind itself.

### Running the app

```
dx serve --port 5001
```

This serves the app at http://localhost:5001 with hot reload. `dx` also watches `tailwind.css` and the sources, and regenerates `assets/tailwind.css` as you edit.

### Building

```
dx build --release
```

The output goes to `target/dx/crustle/release/web/public`.

### Testing and linting

```
cargo fmt --check
cargo clippy --target wasm32-unknown-unknown -- -D warnings
cargo test
```

`assets/tailwind.css` is generated by `dx` and not checked in, and the app refers to it at compile time. On a fresh clone, run `dx build` or `dx serve` once before using plain `cargo` commands, or they will fail with a missing asset error.

CI runs the format check, clippy, the tests and a release build on every push and pull request to `main`.
